# Prevence po transplantaci

Informace pro pacienty po transplantaci orgánu o prevenci nádorů: očkování, kouření, alkohol, pohyb a jídlo, kůže a slunce, pravidelné prohlídky a doporučení podle transplantovaného orgánu.

Připravila MUDr. Soňa Hudecová. Informace slouží ke vzdělávání a nenahrazují konzultaci s lékařem.

Web: https://sonicaopica.github.io/prevence-po-transplantaci/
